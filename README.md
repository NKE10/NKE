# Nakie | Personal Portfolio

A minimalist personal portfolio website showcasing my projects, interests, current goals, and thoughts. Built with a clean visual style, warm neutral colors, and orange accents.

## Pages

- **Home** (`index.html`) - Introduction and portfolio overview.
- **Bio** (`bio.html`) - About me, my background, and interests.
- **Projects** (`projects.html`) - Projects, ideas, and experiments.
- **Now** (`now.html`) - What I'm currently learning and working on.
- **Journal** (`journal.html`) - Notes, reflections, and ideas.
- **Contact** (`contact.html`) - Contact information and a message form.

## Features

- Responsive layout for desktop and mobile.
- Light and dark themes.
- Mobile navigation menu.
- Scroll reveal animations.
- Project category filtering.
- Journal search and category filtering.
- Copy-to-clipboard email button.
- Contact form that opens the user's email application.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: DM Sans, Manrope, and DM Mono

## Getting Started

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the **Live Server** extension, if you haven't already.
4. Right-click `index.html` and select **Open with Live Server**.
5. Explore the website in your browser.

## Project Structure

```text
portfolio/
├── index.html
├── bio.html
├── projects.html
├── now.html
├── journal.html
├── contact.html
├── style.css
├── script.js
└── README.md
```

Add your images, icons, and other assets in an `assets/` folder if needed.

## Customization

- Update the HTML files with your personal information and projects.
- Edit `style.css` to customize colors, typography, spacing, and layout.
- Edit `script.js` to adjust navigation, theme switching, filtering, and animations.
- Replace placeholder email addresses such as `hello@example.com` with your real contact email.

**Important:** The contact form currently opens an email draft. It does not send messages directly or store submissions on a server.
